Tải cấu hình chỉ DNS (Không kèm Root CA)
Hướng dẫn cài đặt Root CA + DNS trên iPhone:
  1. Mở trang này bằng trình duyệt Safari trên iPhone, nhấn Tải cấu hình Root CA + DNS và chọn Cho phép (Allow).
  2. Mở Cài đặt (Settings) → Đã tải về hồ sơ (Profile Downloaded) → nhấn Cài đặt (Install) và nhập mật mã màn hình.
  3. Vào Cài đặt → Cài đặt chung (General) → Giới thiệu (About) → kéo xuống cuối chọn Cài đặt tin cậy chứng nhận (Certificate Trust Settings) → gạt bật công tắc cho LocketGold Research Lab Root CA → chọn Tiếp tục.
  4. Mở lại ứng dụng Locket để áp dụng cấu hình.
Root CA: LocketGold Research Lab Root CA (2 payloads: com.apple.security.root + com.apple.dnsSettings.managed)

Lưu ý: Bắt buộc mở bằng trình duyệt Safari trên iPhone để cài đặt chính xác.
